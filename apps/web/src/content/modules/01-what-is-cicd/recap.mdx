- Continuous integration means committing often and checking every commit automatically, on a machine nobody has tinkered with.
- Delivery adds a releasable artifact and a ready deployment; deployment removes the human button.
- GitHub Actions runs workflows on events, schedules, or outside requests, on hosted or self-hosted machines.
- Actions is free for public repositories on standard hosted runners, and for self-hosted runners.
- Private repositories draw on a monthly quota of minutes that resets each cycle, billed to the repository owner.
