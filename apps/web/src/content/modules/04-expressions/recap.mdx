- Contexts such as `github`, `needs`, `steps`, and `matrix` are read inside `${{ }}`; an unknown context is usually an empty string, not an error.
- Every `if` carries an invisible `success()` unless you write a status function yourself.
- Prefer `if: ${{ !cancelled() }}` over `always()` when you mean "even if something failed".
- A step's `outcome` is before `continue-on-error`, its `conclusion` is after.
- `env` is for this file, `vars` for non-sensitive shared settings (unmasked), `secrets` for credentials.
- Log redaction of secrets is a safety net, not a guarantee, and only covers the current job.
- Small values pass through `$GITHUB_OUTPUT` and `needs`; files pass as artifacts.
